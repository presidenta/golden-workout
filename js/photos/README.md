# Фотографии: фото профиля и «Мой эталон»

Владелец, 04.11.2026: у спорта своё фото, не то, что в «Кванте», — «это всё-таки разные
приложения»; фото должно открываться целиком; нужен раздел, где человек держит фото тела, к
которому идёт, и смотрит на него, пока занимается, — чтобы представить себя уже таким.

## Что видит человек

- **«Мой эталон»** — карточка вверху вкладки «Тренировка». Пусто — пояснение и «Добавить фото».
  Есть фото — лента плиток (листается вбок) и плитка «+». До 12 фото.
- **Эталон над счётчиком подходов** (сборка 33) — всю тренировку, и в подходе, и на отдыхе. В рамке одно фото (сборка 39: прежняя лента вставала «между» снимками); свайп вбок — соседнее, и оно стоит; касание — целиком. Снимки раскрываются заранее — со «Старт подхода» фото на месте сразу.
  «Авто» — меняются сами, интервал 5–60 с (по умолчанию 10); без «Авто» не двигаются. Выбор помнит телефон (meta `auto`).
  Нажатие — открыть целиком.
- **Фото профиля** — кружок в карточке аккаунта (вкладка «Ещё»). Нет фото — нажатие предлагает
  выбрать; есть — открывает его, с кнопками «Сменить» и «Убрать».
- **Просмотр** — во весь экран, на чёрном, снимок целиком без обрезки. Листается пальцем и
  стрелками, закрывается крестиком, Escape и системной «назад».

## Как подключено

Вне этой папки:

- `index.html` — `<link … js/photos/photos.css>`, четыре `<script>` после модуля аккаунта; места
  `#gpGoalCard` (начало `#screenPlan`) и `#gpTrainGoal` (над `#sessionProgress`);
- `js/app.js` — `GFPhotos.start({ dbReady })`;
- `js/ui.js` — системная «назад» сначала закрывает открытое фото (`isOpen`, `close`);
- `js/account/panel.js` — кружок профиля: `GFPhotos.avatar()`, `openAvatar()`, `onChange()`;
- `sw.js` — файлы папки в `STATIC_ASSETS`;
- сервер: `server/src/sport/photos.js` в проекте planner (адреса `/api/sport/photos`).

Начало и конец тренировки модуль замечает сам (по смене класса `#sessionProgress`) — в `ui.js` для этого правок нет.
Убрать модуль — удалить папку и эти строки.

## Снимок

Сохраняется **весь кадр**, без обрезки, в качестве для экрана телефона: лучшая ступень из
`GP_STEPS`, которая влезает в 1 МБ (начинается с 2560 пикселей, JPEG 92 %). Предел — не наш выбор:
перед сервером стоит nginx хоста, его настройка вне репозитория (04.11: 0,9 МБ проходит, 1,1 МБ —
413). Оригинал с камеры не хранится. Перекодирование снимает метаданные камеры: место съёмки на
сервер не уходит. Рядом — копия до 480 пикселей для кружка и плиток.

## Сервер

Без входа фото живут только на телефоне. Со входом — копия на сервере, после переустановки фото
возвращаются. Порядок обмена (`sync.js`): убранное здесь — убрать там; новое здесь — отправить;
потом список с сервера: недостающее — докачать; отправленное, которого на сервере нет, — отправить снова
(сборка 34: прежде стиралось здесь). На телефоне фото убирает только человек; убранное на другом телефоне сюда не доходит.

Хозяин фото — аккаунт: вошёл другой человек — фото прежнего с телефона убираются (у него они на
сервере), как и история тренировок.
