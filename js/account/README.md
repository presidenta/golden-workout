# Аккаунт и сохранение истории

GoldenFit входит аккаунтом «Кванта» и хранит копию истории на его сервере
(`https://game.coreviaflow.com/genesisystem`, модуль `server/src/sport/` в
проекте planner). Позанимался месяц, переустановил телефон, вошёл —
история вернулась. Своих пользователей и паролей у спорта нет.

## Из чего состоит

| Файл | Что внутри |
|---|---|
| `texts.js` | Подписи модуля на ru / ua / en |
| `session.js` | Своя база `GoldenFitAccount` (сессия, курсор, очередь), запросы к серверу, вход по пропуску и по паролю, «Войти через Квант» |
| `sync.js` | Очередь отправки, знакомство на новом телефоне, обмен с сервером |
| `panel.js` | Карточки «Аккаунт» и «Значок на экран», разбор адреса (`#kvant`, `#install`, `#nokvant`), запуск `GFAccount.start()` |
| `account.css` | Вид карточек |

## Как подключено

Вне этой папки:

- `index.html` — `<link … js/account/account.css>`, четыре `<script>` после `ui.js`;
- `index.html` — места `#gfAccountCard` и `#gfInstallCard` в начале вкладки «Ещё»;
- `js/app.js` — `GFAccount.start({ dbReady })` после сборки интерфейса;
- `js/db.js` — `onChange()`: каждая запись сообщает «хранилище, ключ»; `uid` у новой тренировки;
  `raw*()` — запись без сообщения, для пришедшего с сервера;
- `sw.js` — файлы папки в `STATIC_ASSETS`.

Убрать модуль — удалить папку и эти строки; `onChange` и `uid` никому не мешают.

## Вход

1. **Из «Кванта».** Плитка GoldenFit в «Кванте» берёт у сервера одноразовый пропуск
   (2 минуты, один раз) и открывает `…/golden-workout/#kvant=<пропуск>`. Спорт меняет его на свою
   сессию и сразу стирает из адреса. Уже вошли — пропуск не используется.
2. **«Войти через Квант»** (Android) — ссылка
   `intent://goldenfit/login#Intent;scheme=quantumdiary;package=space.coreviaflow.planner;…`.
   Открывается «Квант», он возвращает сюда пропуск. Нет «Кванта» или он старый — Chrome сам
   откроет запасной адрес `#nokvant`, и откроется вход по паролю.
3. **Логин и пароль «Кванта»** — почта или номер кабинета. Для айфона и компьютера.

Регистрации здесь нет: заявку подают в «Кванте», одобряет администратор.

## Что и как сохраняется

| Хранилище | Вид на сервере | Ключ |
|---|---|---|
| `workouts` | `workout` | `uid` (номер `id` — только этого телефона, на сервер не уходит) |
| `daily` | `day` | дата |
| `programs` | `program` | `id` комплекса |
| `settings` | `settings` | `app`, `schedule` |

- Изменение → очередь (`outbox`) → на сервер через 2 секунды, при открытии и при появлении сети.
  Без сети всё работает, очередь ждёт.
- Побеждает более поздняя правка; удаление комплекса доходит до других телефонов.
- **Знакомство** — первый вход аккаунта на этом телефоне: сначала всё с сервера сюда (совпало —
  побеждает сервер), потом своё, чего на сервере нет, — туда. Так возвращается история на новом
  телефоне и уходит на сервер месяц занятий, сделанный до первого входа.
- Пришло с сервера новое — приложение открывается заново (не во время занятия: тогда — когда
  человек его свернёт).
- **Другой аккаунт на том же телефоне** — спрашиваем, заменить ли историю: прежняя уже лежит на
  сервере у своего хозяина.
- Выход оставляет историю на телефоне; новое на сервер не уходит, пока не войдёте снова.

## Значок на экран

Chrome сам предлагает установку (`beforeinstallprompt`) — тогда кнопка «Поставить значок на
экран». Иначе подсказка, где это в меню браузера (на iPhone — «Поделиться» → «На экран „Домой“»).
Открыто со значка — карточка не показывается. `#install` в адресе открывает вкладку «Ещё» и
подсвечивает карточку: так её открывает кнопка «Значок на экран» в «Кванте».
