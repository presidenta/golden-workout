Свои подходы, повторы и темп у каждого упражнения (сборка 42). Владелец 07.11.2026: «делаю доску
синюю — отжимаюсь двадцать, а забито двенадцать, и поменять негде; нужна скорость; общая настройка
неправильная — нужна своя в каждом упражнении».

## Где лежат числа и кто по ним считает

`state.exerciseSettings = { id: { sets, reps, tempo } }` — в записи настроек `app`, она уходит на
сервер. Считают по ним `repsFor`, `tempoFor`, `setsFor` в `js/workout.js` — движок, счёт, список
упражнений, карточка. Чего у упражнения своего нет — как прежде: повторы из описания, подходы из
программы и объёма («Мин/Макс»), темп общий. У статики (планка, удержание) повторы — это секунды, темпа нет.

Поменяли повторы посреди подхода — счёт идёт до нового числа сразу; темп — со следующего подхода.

## Как подключено

- `index.html` — стили и два `<script>` перед `app.js`; плашка `#btnExSettings` в шапке экрана подхода,
  кнопка `#btnPreviewSettings` в карточке упражнения;
- `js/app.js` — `GFExerciseSettings.start({ ui })`;
- `js/ui.js` — `_exerciseSettingsChanged()` перерисовывает список, карточку и подход; новое упражнение
  обновляет подпись плашки; системная «назад» закрывает окно;
- `sw.js` — файлы папки в `STATIC_ASSETS`.
